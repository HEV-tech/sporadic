# СПОРАДИК — сайт радиоклуба

Одностраничный сайт курского радиоклуба «СПОРАДИК» на React + Vite.
Журнальная вёрстка с моноширинным набором, эмблемой из символов, анимациями на anime.js
и двумя темами — тёмной и светлой — с четырьмя палитрами акцента.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # production-сборка в dist/
npm run build:preview   # один самодостаточный dist/index.html (для показа)
npm run preview    # локальный просмотр собранной версии
npm run lint       # eslint
```

Требуется Node 18+.

## Страницы и маршруты

| `/sport` | что такое радиоспорт |
| `/sport/events` | спортивные мероприятия |
| `/sport/diplomas` | дипломная программа |
| `/tourism` | что такое радиоэкспедиция |
| `/tourism/expeditions` | радиоэкспедиции клуба |
| `/projects/victory` | радиоэкспедиции «ПОБЕДА» |
| `/projects/fox-hunt` | проект «Охота на лис» |
| `/projects/marathon` | радиомарафон «Курская битва — 75» |
| `/projects/kursk-battle` | комплекс мероприятий в память о Курской битве |
| `/projects/engineering` | научно-испытательная площадка |
| `/projects/literacy` | развитие технической грамотности |
| `/history` | история клуба: таймлайн, позывные, цифры |
| `/charter` | устав клуба с оглавлением |
| `/archive` | хроника событий клуба |
| любой другой | страница 404 |

Материалы разделов «Радиоспорт», «Туризм» и «Проекты» живут внутри проекта:
тексты лежат в `src/data/articles.js`, адреса — в таблице выше. Внешних ссылок
на старый сайт в приложении не осталось.

Роутинг — `react-router-dom`. На хостинге это обычные адреса (`BrowserRouter`);
если `index.html` открывают прямо с диска (`file://`), история браузера недоступна,
поэтому включается `HashRouter` — адреса становятся вида `#/history`.

Для выкладки на сервер нужен SPA-fallback: все пути отдают `index.html`
(в nginx — `try_files $uri /index.html;`), иначе прямой заход на `/history` даст 404.

`base` в `vite.config.js` зависит от режима: обычная сборка — `/` (иначе на
вложенных адресах вроде `/sport/events` ассеты дают 404 и страница пустая),
режим `single` — `./`, потому что такой файл открывают с диска.

## Навигация

В шапке четыре раздела с выпадающими списками: «Радиоспорт», «Экспедиции»,
«Проекты», «Клуб». Список раскрывается по наведению и по Tab (не по клику —
щелчок по названию ведёт на страницу раздела), его ширина равна ширине
плашки раздела, верхние углы почти прямые, нижние — скруглённые.
На узких экранах разделы живут в полноэкранном меню, где подпункты стоят
под заголовком с вертикальной линией.

Поле «Что интересно» в форме — не `select`, а такой же список: ширина как у
поля, скруглён снизу, раскрывается вниз, а если места мало — вверх
(тогда скругляются верхние углы). Работает мышью, стрелками, Enter и Escape.

## Дизайн-система

Все значения — в `:root` в начале `src/styles.css`:

- темы: `data-theme="dark"` и `data-theme="light"` на `<html>`, каждая со своим набором фонов,
  текста и линий; выбор хранится в `localStorage` и ставится инлайн-скриптом до первой отрисовки;
- палитры: `data-palette` — янтарь, фосфор, ионосфера, медь; у каждой свой акцент для тёмной
  и светлой темы (светлые варианты темнее — ради контраста на бумаге);
- шрифты не системные и лежат в бандле: `Unbounded` для заголовков, кнопок и цифр,
  `JetBrains Mono` для текста и эмблемы (Fontsource, файлы в сборке, без запросов в сеть);
- радиусы — одна шкала `--r-xs … --r-pill`: прямых углов нет, кнопки и навигация круглые (`--r-pill`),
  карточки — 28–36 px, поля и картинки — 14–28 px;
- сетка: контейнер 1240 px, боковые отступы 40/24/20 px, секции 96/64 px;
- тени: в светлой теме карточки приподняты мягкой тенью, в тёмной — почти без неё.

## Темы и палитры

`src/lib/theme.js` держит список палитр и хук `useTheme`: он пишет `data-theme` / `data-palette`
на `<html>` и запоминает выбор. Начальное состояние выставляет инлайн-скрипт в `index.html`:
он читает `localStorage`, а без сохранённого выбора — `prefers-color-scheme`.
Переключатель — `ThemeControls`: цветные точки палитр и кнопка темы. На десктопе он живёт в шапке,
на мобильном — в меню.

Чтобы добавить палитру: допишите её в `PALETTES` и задайте два правила в `styles.css`
(`[data-palette='…']` для тёмной и `[data-palette='…'][data-theme='light']` для светлой).

## Движение

Все появления, каскады и открытие меню — на `anime.js` (`src/lib/motion.js`).

- `revealElement` — блок всплывает и проявляется, когда его ловит `IntersectionObserver`;
  после анимации inline-трансформация снимается, чтобы не мешать hover-эффектам;
- `printEmblem` — строки эмблемы печатаются каскадом (`stagger`);
- `revealWords` — слова слогана догоняют друг друга;
- `heroIntro` — таймлайн первого экрана: эмблема, подпись, заголовок, текст, кнопки, панель фактов;
- `openMenuTimeline` / `closeMenuTimeline` — подложка меню и ссылки лесенкой.

Микро-взаимодействия (hover, нажатие, фокус) остались в CSS: это отклик на состояние,
а не сюжетная анимация. При `prefers-reduced-motion: reduce` все движения отключаются —
элементы сразу показаны, без сдвигов.

## Эмблема из символов

Эмблема — не картинка, а текст. `AsciiEmblem` берёт `src/assets/sporadic-logo-9f3c.png`,
считает полутон по символьной сетке и рендерит `<pre>` из 68 строк. Всё происходит
в браузере: отдельной сборки арта, препроцессоров и внешних утилит нет.

- `src/lib/asciiEmblem.js` — сама конверсия: обрезка по альфа-каналу, средняя яркость
  по клеткам, размытие по сетке, гамма и раскладка по градациям;
- параметры (`columns`, `gamma`, `blur`, `ramp`) — аргументы `buildRows`,
  значения по умолчанию лежат в `src/lib/asciiEmblem.js`;
- кегль подбирается замером ширины строки: у разных моноширинных шрифтов разная
  ширина знака, и только замер гарантирует, что блок займёт ровно свою колонку.

Поменять логотип — заменить картинку в `src/assets/` и поправить импорт в `Hero.jsx`,
эмблема пересчитается сама.

## Поведение и доступность

- меню: `aria-expanded`, фокус уходит на первую ссылку, `Escape` закрывает и возвращает фокус,
  фон получает `inert` и не скроллится;
- форма: валидация на клиенте, ошибки связаны через `aria-describedby`, статус в `aria-live`;
  письмо собирается как `mailto:` — бэкенда нет, поэтому «отправлено» не имитируется;
- ссылка «Перейти к содержанию», видимый фокус, семантические `section`/`footer`/`details`;
- изображения с `alt`, `width`/`height` и `loading="lazy"`.
